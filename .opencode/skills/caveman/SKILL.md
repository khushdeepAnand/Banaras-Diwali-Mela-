# Caveman

- Inspect the authoritative baseline, relevant callers and tests before editing.
- Follow token-efficient-coding and the task's domain skill; reuse existing code.
- Keep a short gap checklist; patch only evidenced gaps. No unrelated features.
- Read unchanged files once. Use focused searches and parallel independent checks.
- Never trade security, readable code, truthful persistence or required tests for tokens.
- Report exact executed commands, failures, blockers and unverified live dependencies concisely.
- Stop at acceptance. This skill describes workflow, never characters or assets.
